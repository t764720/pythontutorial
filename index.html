الدرس الثاني: المتغيرات والثوابت في بايثون

دليل تعليمي وتفاعلي مبسط لفهم كيفية تخزين البيانات والتعامل مع المتغيرات البرمجية

1 فتح بيئة التطوير وتدشين الملفات (IDLE)

لكتابة وتشغيل البرامج بلغة بايثون، نستخدم بيئة التطوير المتكاملة Python IDLE:

  • اضغط على زر Start (بدء).
  • مَرِّر للأسفل ثم اضغط على مجلد Python 3.9.
  • اختر IDLE (Python 3.9 64-bit).
  • لإنشاء ملف برمجي جديد وكتابة الأوامر وحفظها، من قائمة File اختر New File (أو اضغط Ctrl + N).
# مثال لطباعة رسالة ترحيبية print("مرحبا بك في بايثون")

2 المتغيرات (Variables)

المتغير هو مكان محجوز في ذاكرة الحاسب لتخزين قيمة قد تتغير أثناء تنفيذ البرنامج. تنقسم المتغيرات إلى أنواع أساسية منها:

  • الأعداد (Numeric): مثل الأعداد الصحيحة (Integer) والعشرية (Float).
  • النصوص (String): سلاسل نصية توضع دائماً بين علامتي تنصيص " ".

شروط تسمية المتغيرات:

  • أن تبدأ بحرف أو بشرطة سفلية _.
  • ألا تبدأ برقم أبداً.
  • حالة الحروف الإنجليزية مهمة جداً (حساسة لحالة الأحرف، مثال: age تختلف تماماً عن Age).
  • ألا تكون كلمة محجوزة خاصة بلغة بايثون مثل print أو input أو True أو False وغيرها من الكلمات...
# أمثلة على تعيين القيم للمتغيرات score = 1200 myName = "محمد" print("اسمي:", myName) print("درجتي:", score)

3 الثوابت (Constants)

هي متغيرات ذات قيمة ثابتة لا تتغير أثناء تنفيذ البرنامج (مثل قيمة النسبة الثابتة π التي تساوي تقريباً 3.14). وعادة ما يتم استيرادها من مكتبات بايثون الجاهزة:

from math import pi print("قيمة باي:", pi)

4 التعليقات (Comments)

تُستخدم التعليقات لإضافة تلميحات وشروحات حول التعليمات البرمجية ولا تُعد من خطوات المقطع البرمجي. قد تحتاج إلى مراجعة التعليقات في المستقبل إذا رغبت بإجراء أي تغييرات على برنامجك.

يمكنك إضافة ما تريده من تعليقات باستخدام علامة الشباك (#) في بداية العبارة، وسيتجاهلها جهاز الحاسب تماماً ولا ينفذها.

# ....هذه عبارة عن تعليقات لا ينفذها جهاز الحاسب # عين قيمة لاسم المتغير name = "محمد" # اطبع قيمة المتغير print("اسمي:", name)
