مرحباً بك في عالم البرمجة بلغة Python - المهارات الرقمية

1. فتح بيئة التطوير وتدشين الملفات (IDLE)

لكتابة وتشغيل البرامج بلغة بايثون، نستخدم بيئة التطوير المتكاملة Python IDLE[cite: 1]:

  • اضغط على زر Start (بدء)[cite: 1].
  • مَرِّر للأسفل ثم اضغط على مجلد Python 3.9[cite: 1].
  • اختر IDLE (Python 3.9 64-bit)[cite: 1].
  • لإنشاء ملف برمجي جديد وكتابة الأوامر وحفظها، من قائمة File اختر New File (أو اضغط Ctrl + N)[cite: 3].
# مثال لطباعة رسالة ترحيبية print("مرحبا بك في بايثون")

2. المتغيرات (Variables)

المتغير هو مكان محجوز في ذاكرة الحاسب لتخزين قيمة قد تتغير أثناء تنفيذ البرنامج[cite: 6]. تنقسم إلى:

  • الأعداد (Numeric): مثل الأعداد الصحيحة (Integer) والعشرية (Float).
  • النصوص (String): سلاسل نصية توضع دائماً بين علامتي تنصيص " "[cite: 6, 8].

شروط تسمية المتغيرات:

  • أن تبدأ بحرف أو بشرطة سفلية _[cite: 7].
  • ألا تبدأ برقم أبداً[cite: 7].
  • حالة الحروف الإنجليزية مهمة جداً (مثال: age تختلف عن Age)[cite: 7].
# أمثلة على تعيين القيم للمتغيرات score = 1200 myName = "محمد" total = x + y print("اسمي:", myName)

3. الثوابت (Constants)

هي متغيرات ذات قيمة ثابتة لا تتغير أثناء تنفيذ البرنامج (مثل قيمة النسبة الثابتة $\pi$ التي تساوي تقريباً 3.14)[cite: 9]. وعادة ما يتم استيرادها من مكتبات بايثون الجاهزة[cite: 9]:

from math import pi print("قيمة باي:", pi)
